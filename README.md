# MrHeaven1y.social

The single static social hub for Dibyendu Mukherjee. LinkedIn is the publishing category and the single home for these notes.

## Branch map

- **Portfolio** — live at [mrheaven1y.github.io](https://mrheaven1y.github.io/)
- **Social hub** — live at [mrheaven1y.github.io/social](https://mrheaven1y.github.io/social/)
- **LinkedIn notes** — live at [/linkedin](https://mrheaven1y.github.io/social/linkedin/)
- **LinkedIn profile** — [Dibyendu Mukherjee](https://www.linkedin.com/in/dibayendu-mukherjee-bb897b267)
- **X / Twitter** — reserved at `/x/`
- **Medium** — reserved at `/medium/`

## Folder structure

```
content/linkedin/          Markdown source (frontmatter + metadata)
assets/
  site.css, content.css     Site styles
  app.js, search.js         Client scripts
  linkedin/[slug]/          Post assets (article.html, PDF, TeX, images)
scripts/
  build-social.mjs          Generates routes, index.json, sitemap, RSS
  validate-social.mjs       Checks build output
index.html                  Home page (platform cards; stats patched by build)
portfolio/, medium/, x/     Static branch pages

# Generated by npm run build (gitignored; CI rebuilds before deploy)
linkedin/                   Category + post pages
tags/                       Topic archives
page/                       Paginated archives
index.json                  Client-side search index
sitemap.xml, feed.xml       Discovery feeds
```

## Content model

LinkedIn notes live in [`content/linkedin`](content/linkedin). Each Markdown file owns its frontmatter: title, platform, topics, date, summary, handnote, and external LinkedIn URL. Post bodies and downloadable assets live in [`assets/linkedin/[slug]`](assets/linkedin).

```powershell
npm run check
```

The build emits `/linkedin/`, topic archives under `/tags/`, paginated archives under `/page/`, `/index.json`, `sitemap.xml`, and `feed.xml`.

## Deployment

The site is dependency-free and deploys through GitHub Pages using `.github/workflows/deploy.yml`. The workflow builds content before deploy. If Pages is not enabled, set **Settings → Pages → Source** to **GitHub Actions** once, then rerun the workflow.
